How it works

  1. Load prices — daily modal prices per crop & mandi (CSV, Agmarknet format).
  2. Four models race — Seasonal Naive, 7-day Moving Average, 30-day Linear Trend, and an Ensemble median of all three.
  3. Backtest picks the winner — lowest MAPE over the last 21 days, no look-ahead.
  4. Forecast 7 days — with a 95% confidence band from the backtest error spread.
  5. Name the best day — the highest forecast price, and what waiting is worth.
Sample data: the bundled prices are illustrative, not real market data. Bring a real Agmarknet export via the upload above — or run the Java CLI on it. Built in a day · github.com/qasimjethwa/mandilens
